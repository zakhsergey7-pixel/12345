# Трекер расходов

Дашборд для сведения трат с трёх карт (Т-Банк, Точка — счёт ИП, Озон Банк) с разметкой каждой операции как «личное»/«рабочее», категориями и обзором расходов за день/неделю/месяц/полгода.

Сайт: https://zakhsergey7-pixel.github.io/12345/

## Файлы

- `index.html` — дашборд. Работает в двух режимах:
  - внутри чата Claude — хранит данные через `window.storage`;
  - вне чата (на GitHub Pages) — стучится в Apps Script по HTTP. URL и пароль задаются через иконку-шестерёнку в правом верхнем углу и сохраняются в localStorage браузера.
- `Code.gs` — Google Apps Script, разворачивается как Web App поверх Google Таблицы (лист «Транзакции»). Служит API для сайта, принимает вебхук Точка.API и разбирает письма Озон Банка по расписанию.

## Настройка

1. Создайте Google Таблицу, откройте Extensions → Apps Script, вставьте `Code.gs`.
2. В `Code.gs` замените `SHARED_SECRET` на свой пароль.
3. Deploy → New deployment → Web app, Execute as: Me, Who has access: **Anyone**. Скопируйте URL.
   (При последующих правках кода редактируйте это же развёртывание через Deploy → Manage deployments — иначе URL сменится и все вебхуки/шорткаты придётся перенастраивать.)
4. В триггерах (значок часов) добавьте time-driven trigger на `checkGmailForTransactions`, каждые 10 минут.
5. Откройте `index.html` (на GitHub Pages), нажмите на шестерёнку, впишите URL и пароль.
6. Точка.API: получите JWT-токен (Интеграции → API), создайте вебхук на URL из шага 3. Сверьтесь с реальным payload и при необходимости поправьте `parseTochka_` в `Code.gs`.
7. Озон Банк: включите email-уведомления в приложении банка. При необходимости поправьте `OZON_SENDER_QUERY` и регулярку в `parseOzonEmail_` под реальный формат письма.
8. Т-Банк: официального API для физлиц нет. Ввод — вручную через кнопку «+ Операция» на сайте, либо шорткатом iPhone (POST на URL из шага 3 с `secret` и полями `date`/`desc`/`amount`/`source`).
